Лабораторная 3. Скорость волны на мелкой воде

Распакуй архив на Raspberry Pi, открой терминал в папке wave. Все команды ниже выполняй из неё.
Для платы нужны RPi.GPIO и smbus2. Для финальных графиков нужны numpy и matplotlib. Если их нет в системном Python Raspberry Pi OS:
sudo apt install python3-rpi.gpio python3-smbus2 python3-numpy python3-matplotlib

Включи I²C на плате. Для учебной установки после перезагрузки выполни:
raspi-gpio set 2 a0
raspi-gpio set 3 a0

1. python3 scripts/door.py
Закрой дверцу — увидишь 1. Открой — увидишь 0. Повтори пять раз. Остановка Ctrl+C.

2. python3 scripts/water_level.py
На экране только код АЦП от 0 до 1023. Долей воды, проверь, меняется ли число. Сверь изменение напряжения мультиметром. Остановка Ctrl+C.
При необходимости посмотреть младшие три бита отдельно запусти python3 scripts/bits.py.

3. python3 scripts/frequency.py
Подожди 10 секунд. Запиши среднюю частоту АЦП в герцах (число отсчётов, делённое на длительность). Для опыта требуется больше 100 Гц.

4. python3 scripts/calibrate.py
Закрой дверцу. Выставь у электродов 20 мм по линейке. Введи 20, дождись спокойной воды и нажми Enter. Через 10 с появится data/calibration/20 mm.txt. Запусти программу ещё четыре раза для 40, 60, 80 и 100 мм. Электроды оставь в том же положении.

5. python3 scripts/waveMeasure.py
Дважды измерь расстояние L от дверцы до электродов и запиши среднее в метрах. Подставь ёмкость, закрой дверцу, налей воду до 20 мм и дождись покоя. Запусти скрипт, введи 20 и дождись приглашения. Резко открой дверцу. Через 15 с файл появится в data. Повтори для 40, 60, 80 и 100 мм. При повторе на той же глубине предыдущая запись заменяется. Если нужны обе, сначала скопируй старый файл.

6. python3 scripts/waveProcessing.py
Можно запускать на компьютере, сохранив структуру папки wave. Введи своё L в метрах. В plots появятся калибровочная кривая, пять графиков уровня, графики скорости от глубины в обычных и логарифмических координатах и таблица results.csv. Скорость опыта c = L / τ. Для сравнения со значением √(gh) глубину переводим в метры.
Открой пять графиков. Красная линия должна стоять в начале устойчивого спада после короткого дрожания воды. Если автоматика промахнулась, задай два времени в секундах на прямом участке спада именно этой записи. Например, FIT_INTERVALS = {40: (1.72, 1.95)} в scripts/waveProcessing.py. Подставь времена со своего графика и запусти снова. Ниже 20 и выше 100 мм уровень оценивается продолжением калибровки по касательной.
Для отчёта сохрани исходные измерения, своё L, графики, таблицу, фото установки и хода опыта. Сравни измеренный наклон на логарифмическом графике с 0,5.

mcp3021_driver.py и wave_data.py используются остальными программами. Отдельно их запускать не требуется. В драйвере установлен адрес АЦП 0x4D. Если у вашей платы адрес другой, возьми его из своего драйвера с прошлого занятия.
