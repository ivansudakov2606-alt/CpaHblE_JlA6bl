## Этап 1. Подготовка в аудитории (30–40 мин)

### Экспериментатор
1. Создать на рабочем столе папку со своим именем.
2. Скопировать в неё `waveFunctions.py` из стартового набора.
3. Создать пустой `waveMeasure.py` и импортировать: `import waveFunctions as b`.
4. Настроить GPIO 9, 10, 11 для SPI по видео-инструкции.
5. Убедиться, что с АЦП читаются не нули (`read_adc()` ≠ 0).

### Программист (вы)
1. Проверить, что `process_data.py` запускается и рисует графики на тестовых данных.
2. Подготовить шаблон папки `results/` и убедиться, что `matplotlib` работает.

### Руководитель
1. Создать пустой документ отчёта (титульный лист, структура по критериям).
2. Сделать первые фото экспериментальной установки.

## Этап 2. Калибровка (40–60 мин)

Экспериментатор запускает `waveMeasure.py` для каждого уровня воды (каждая измеряется 10 секунд):

```bash
python waveMeasure.py calibrate 20 10
python waveMeasure.py calibrate 40 10
python waveMeasure.py calibrate 60 10
python waveMeasure.py calibrate 80 10
python waveMeasure.py calibrate 100 10
python waveMeasure.py calibrate 120 10
```

Результат: файлы в `measurements/`:
- `calibrate_20mm.txt`, `calibrate_40mm.txt`, …, `calibrate_120mm.txt`

**Баллы:** 6 баллов (по 1 за каждый уровень).

---

## Этап 3. Измерение расстояния дверь → электроды (5–10 мин)

Экспериментатор измеряет линейкой расстояние от торцевой двери кюветы до электродов (в мм).

**Балл:** 1 балл.  
Это значение нужно подставить в `process_data.py` в переменную `DOOR_TO_ELECTRODES_MM`.

---

## Этап 4. Замеры пробега волны (30–40 мин)

Экспериментатор запускает замер для каждого уровня (15 секунд после открытия двери):

```bash
python waveMeasure.py measure 120   # ждём открытия двери, потом 15 сек
python waveMeasure.py measure 80
python waveMeasure.py measure 40
```

Результат:
- `measure_120mm.txt`, `measure_120mm_t.txt`
- `measure_80mm.txt`, `measure_80mm_t.txt`
- `measure_40mm.txt`, `measure_40mm_t.txt`

**Баллы:** 3 балла (по 1 за каждый уровень).

---

## Этап 5. Обработка данных — ваша задача (30–60 мин)

Запустить:

```bash
python process_data.py
```

Скрипт сделает автоматически:

1. **Калибровку:** найдёт полиномиальную зависимость уровня воды от показаний АЦП (4 балла).
2. **Графики:** построит 3 графика уровня vs время для уровней 120, 80, 40 мм (3 балла).
3. **Скорость волны:** определит время прихода волны и рассчитает `v = L / t`, нанесёт на графики (3 балла).
4. Сохранит графики в `results/*.png` и итоговую таблицу в `results/summary.txt`.

### Если нужно ускорить/уточнить определение времени прихода
В `process_data.py` есть настройка:
```python
THRESHOLD_FRAC = 0.25   # 0.15–0.3 — чем меньше, тем раньше фиксируется приход
```
Автоматическое определение дает **+1 балл** (по желанию).
