## Этап 1. Экспериментатор: подготовка и сбор

### п3.1 — Датчик открытия дверцы (без баллов)
- Проверить геркон на GPIO15: 1 при закрытой дверце, 0 при открытой.
- Скрипт `waveMeasure.py` ждёт открытия дверцы (реметод п3.1) — уже реализован в `wait_door_open()`.

### п3.2 — Датчик уровня и скрипт измерений (без баллов)
- Подключить выход датчика уровня к разъёму 5 В платы get-adc.
- Проверить мультиметром: напряжение меняется с уровнем.
- Проверить АЦП MCP3021 по I2C: `adc.get_number()` при доливании воды.
- Частота дискретизации — выше 100 Гц (на установке ~1840 Гц).

### п3.3 — Калибровка уровня воды (5 баллов: по 1 за уровень)
Для каждого уровня 20, 40, 60, 80, 100 мм:
1. Налейте воду до нужного уровня, жди, пока поверхность успокоится.
2. Запись 10 секунд **без** ожидания дверцы:
   ```bash
   python waveMeasure.py calibrate 20 10
   python waveMeasure.py calibrate 40 10
   ...
   python waveMeasure.py calibrate 100 10
   ```
3. Файлы сохраняются в `data/calibration/20 mm.txt … 100 mm.txt`.
4. Проверить: средний отсчёт растёт с уровнем (монотонность), внутри файла нет скачков.

### п3.4 — Измерение скорости волны (5 баллов: по 1 за опыт)
1. **Измерить расстояние L** от дверцы до электродов (рулеткой, дважды).
2. Для каждого уровня:
   ```bash
   python waveMeasure.py measure 20 15
   python waveMeasure.py measure 40 15
   ...
   python waveMeasure.py measure 100 15
   ```
3. Открывайте дверцу **резко**, одним движением.
4. Файлы сохраняются в `data/wave H mm.txt`.
5. Проверить сразу: в начале записи уровень постоянный, потом падает (излом виден).

## Этап 2. Программист: обработка данных (ваш этап — 10 баллов + 1)

### Подготовка
1. Измерить/узнать **L** (дверца → электроды, в метрах).
2. Установить в `waveProcessing.py` переменную `L` (в примере пособия L = 1.00 м).
3. Запустить:
   ```bash
   python waveProcessing.py
   ```

### Что скрипт делает

**п3.5 — Калибровочная зависимость (4 балла):**
- Средние отсчёты по файлам калибровки.
- Подбирает многочлен 3-й степени (уровень = f(отсчёт)).
- Проверяет отклонения точек от кривой (должно быть несколько мм).
- Сохраняет `height-calibration.png`.

**п3.6 — Скорость волны (6 баллов):**
- Для каждого опыта: перевод отсчётов в уровень, сглаживание 0.3 с (убирает дрожь дверцы).
- Поиск τ **методом двух прямых**:
  1. Средний уровень на участке 0.2–0.5 с (до волны).
  2. Первая точка, где уровень упал ниже порога (максимум из 5·шум и 1.0 мм).
  3. Прямая по началу спада (0.3 с).
  4. τ = пересечение с горизонталью «до волны».
- Скорость c = L / τ.
- Сохраняет `wave H mm.png` с τ и рамкой (L, τ, c).
- **+1 балл** — автоматический поиск τ уже реализован.

**Сравнение с теорией (2 балла):**
- `speed-from-depth.png` — график c = √(gh) + экспериментальные точки.
- `ln-speed-from-depth.png` — ln c от ln h, наклон ≈ 0.5 ± погрешность.

**Таблица:** `plots/results.csv`.

### Что проверить в результатах
- Скорости растут с глубиной.
- При 20–40 мм расхождение с теорией в несколько %.
- Наклон ln c от ln h близок к 0.5 (в пределах погрешности).
- При 100 мм датчик может быть у предела — обсудите в отчёте.

## Этап 3. Отчёт (Руководитель — п3.7, 10 баллов)

Структура отчёта:
1. Титульный лист
2. Введение: цель, задачи
3. Теория: приближение мелкой воды, датчик уровня (делитель напряжения), геркон, установочные формулы
4. Программа и методика: калибровка, измерения, обработка
5. Эксперимент: калибровка, графики уровня от времени, сравнение скоростей с теорией
6. Результаты: таблица уровень–τ–c, наклон в логарифмах
7. Вывод: подтверждается ли c = √(gh), источники погрешности

Графики берутся из `plots/`.
