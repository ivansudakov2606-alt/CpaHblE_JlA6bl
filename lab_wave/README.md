# Лабораторная работа: «Скорость волны на поверхности воды»

Готовый набор скриптов и план_actions для команды.  
Ваша роль — **Программист (обработка данных)**.  
Все скрипты уже отлажены на синтетических данных и готовы к работе в аудитории.

## Содержимое папки

| Файл | Назначение | Кто запускает |
|------|-----------|---------------|
| `waveFunctions.py` | Стартовый набор функций (чтение АЦП, геркон, сохранение) | Экспериментатор (входит в его скрипт) |
| `waveMeasure.py` | Сбор данных: калибровка уровней + замеры пробега волны | Экспериментатор |
| `process_data.py` | Обработка: калибровочный полином, графики, скорость волны | **Программист (вы)** |
| `generate_synthetic.py` | Генератор тестовых данных (для отладки без оборудования) | Вы (для проверки) |
| `requirements.txt` | Python-зависимости | — |
| `PLAN.md` | Пошаговый план выполнения работы | Вся команда |
| `measurements/` | Сырые файлы с показаниями АЦП (создается автоматически) | — |
| `results/` | Графики PNG и `summary.txt` (создается автоматически) | — |

## Быстрый старт (уже проверено)

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Сгенерировать тестовые данные и проверить конвейер
python generate_synthetic.py
python process_data.py

# 3. Посмотреть результаты
ls results/
cat results/summary.txt
```

## Что делать в аудитории

1. Экспериментатор настраивает АЦП (GPIO 9, 10, 11) и проверяет `waveFunctions.py` на реальном железе.
2. Экспериментатор собирает калибровку (уровни 20–120 мм) и три замера (120, 80, 40 мм).
3. **Вы** запускаете `python process_data.py` — получаете графики и скорости.
4. Руководитель вставляет графики в отчёт и пишет вывод.

Подробный план — в файле `PLAN.md`.
