# Лабораторная работа: «Скорость волны на поверхности воды»

Готовый набор скриптов и план для команды, выстроенный строго по
пособию МФТИ 2025 (п3.1–п3.7, т3.1–т3.5).

## Ваша роль — Программист (обработка данных)

**Ваша задача:** п3.5 (калибровка, 4 балла) + п3.6 (скорость волны, 6 баллов,
+1 за автоматический поиск τ).  
**Результат:** `waveProcessing.py` + графики в `plots/`.

## Содержимое папки

| Файл | Назначение | Кто использует |
|------|-----------|----------------|
| `waveFunctions.py` | Общие функции: АЦП (MCP3021 по I2C), геркон (GPIO15), save/read формата о3 | Экспериментатор |

| `PLAN.md` | Пошаговый план по этапам п3.1–п3.7 | Вся команда |

## Ступени конвейера (проверено на синтетических данных)

```bash
# 1. Деpendencies
pip install -r requirements.txt

# 2. Тестовые данные (формат: - Wave Lab / duration count / отсчёты)
python generate_synthetic.py

# 3. Обработка
python waveProcessing.py

# 4. Результаты
ls plots/
```

## Что делает `waveProcessing.py` (п3.5 + п3.6)

1. **Калибровка (п3.5):** по файлам `data/calibration/20 mm.txt … 100 mm.txt`
   подбирает многочлен 3-й степени, переводящий отсчёт АЦП в уровень воды.
   Сохраняет график `height-calibration.png`.
2. **τ и скорость (п3.6):** для каждого опыта `wave H mm.txt`:
   переводит отсчёты в уровень, сглаживает (0.3 с, убирает дрожь дверцы),
   ищет момент прихода волны **методом двух прямых**, считает `c = L / τ`.
   Сохраняет `wave H mm.png` с отмеченным τ и рамкой L, τ, c.
3. **Сравнение с теорией:** графики `speed-from-depth.png` (c = √(gh)) и
   `ln-speed-from-depth.png` (ln c от ln h, наклон ≈ 0.5).
4. **Таблица:** `plots/results.csv`.

## Перед запуском в аудитории

В `waveProcessing.py` установите **реальное** расстояние дверца → электроды
(в переменной `L`, в метрах). В примере пособия L = 1.00 м.

## Что даёт +1 балл

Автоматический поиск момента прихода волны методом двух прямых — уже
реализован в `waveProcessing.py` (`find_tau_two_lines`).

## Аппаратные примечания

`waveFunctions.py` имеет демо-режим (`DEMO_MODE = True`) — без оборудования
скрипт запускается и тестируется. Для реального железа (Raspberry Pi +
MCP3021 по I2C + геркон на GPIO15) поставьте `DEMO_MODE = False` и
запустите скрипт с драйвером `mcp3021_driver.py` из репозитория `get`.
